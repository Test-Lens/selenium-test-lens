# Published API boundary

**Selenium Test Lens 0.1.0 — stable**

Version 0.1.0 publishes the core, overlay, main Selenium, and React JARs. Its authoritative binary reference is the [0.1.0 Javadoc](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens/0.1.0/).

Development-only modules and symbols are deliberately absent from this snapshot and are checked against the audited `v0.1.0..main` boundary. Do not copy API reference pages from `main` into this immutable snapshot.

Direct module references:

- [core](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens-core/0.1.0/)
- [overlay](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens-overlay/0.1.0/)
- [main Selenium artifact](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens/0.1.0/)
- [React helpers](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens-react/0.1.0/)
