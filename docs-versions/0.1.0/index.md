# Selenium Test Lens 0.1.0

This is the immutable documentation snapshot for the latest release currently available from Maven Central: **0.1.0**.

It is intentionally narrower than the [development documentation](https://test-lens.github.io/selenium-test-lens/dev/). The `main` branch develops 0.2.0 and contains APIs and modules that are not present in 0.1.0.

The snapshot is derived from tag [`v0.1.0`](https://github.com/Test-Lens/selenium-test-lens/tree/v0.1.0), its POMs, README, changelog, and published API. It must not be updated from `main` after publication.

Start with [installation](installation.md) or [the basic session](getting-started.md). For exhaustive signatures use the [published Javadoc](https://javadoc.io/doc/io.github.test-lens/selenium-test-lens/0.1.0/).
