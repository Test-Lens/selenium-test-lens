# 0.5.0 publication candidates

!!! warning "Not a release announcement"
    This page records packaging candidates for review. The current reactor still sets `maven.deploy.skip` for every module listed below, and Maven 0.4.0 does not contain these APIs. No artifact coordinate on this page is a promise that 0.5.0 has been published.

The current source vertical slice separates deterministic product layers from local orchestration:

| Candidate boundary | Intended consumer role | Current decision needed |
|---|---|---|
| `selenium-test-lens-application-model` | Selenium-free, versioned `ApplicationModel` contracts | Confirm long-term schema/read compatibility and intentional public API. |
| `selenium-test-lens-application-mapper` | Explicit current-page/guided mapping backed by Selector Intelligence | Decide how required selector engine/live dependencies are packaged and supported. |
| `selenium-test-lens-application-tooling` | Persistence, Page Object generation, drift, context and workflow contracts | Separate supported offline API from trusted-host/internal orchestration before publication. |
| `selenium-test-lens-test-engineering-studio` | Local loopback UI and launcher | Prefer a deliberate tooling distribution/launcher contract rather than adding Studio to normal runtime dependencies. |
| selector engine/live/tooling prerequisites | Existing ranking, live validation, source indexing and correlation | Publish only the minimum supported dependency surface; Selector Lab remains a separate tooling decision. |

## Required release evidence

Before any candidate becomes a consumer artifact, the release must establish:

- explicit `USER_API`, low-level and internal boundaries in the public API manifest, with correct `@since` data;
- binary/source API gates and clean-room Maven/Gradle consumer compilation for the chosen coordinates;
- dependency isolation: no Selenium in the neutral model, and no JavaParser, browser driver, CLI provider SDK or Studio frontend in normal runtime transitively;
- real Chrome and Firefox mapper contracts, deterministic model and generator tests, generated-source compilation, context-size bounds and security/redaction tests;
- a supported launcher/distribution story for Studio, including project configuration, workspace placement, external agent and WebDriver integration boundaries;
- versioned documentation built from the exact release source and a clear migration/read-compatibility policy for stored models and workflow snapshots;
- release packaging validation updated intentionally, rather than merely removing an artifact from `excludeArtifacts`.

The 0.4.0 tag, Maven artifacts and numeric documentation must remain immutable. Development documentation may describe this source-only work, but stable pages must not claim availability until the corresponding artifacts and launch path pass the release gates.
