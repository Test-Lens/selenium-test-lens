    Exhaustive public API catalog¶

    This generated catalog is the optional binary-surface reference for every published public type, constructor, method, and field. Start with Capabilities and the functional navigation for behavior, workflows, and examples. Internal-style types appear only because Java consumers can currently access them.

    Inventory: 231 public types and 1818 public callable methods/constructors (including public nested types and compiler-generated record/enum members).

    Classifications: USER_API is the normal consumer path; ADVANCED_API is supported specialized functionality; LOW_LEVEL_API exposes lower abstractions; INTERNAL_STYLE_PUBLIC is binary-public implementation surface and is not recommended for application code.

    Signature details are split by published artifact and Java package to keep individual pages usable. These generated pages are excluded from site search.
